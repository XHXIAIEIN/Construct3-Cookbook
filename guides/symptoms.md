# Event Sheet Symptoms

Sources and the rule for adding an entry are in the index,
[pitfalls.md](pitfalls.md).

If events do not do what you expect, find what you see here and check its
causes in order. Each cause links the page whose entry states the fix and
its source.

| Symptom | Causes to check, in order |
|---------|---------------------------|
| A click or tap does nothing | 1. The trigger is in a sheet that the layout neither uses nor includes: [Event sheet includes](primitives/events/includes.md). 2. The button's layer is not interactive, or the button is outside the viewport: [Touch](plugins/touch.md). 3. A Mouse condition ignores a finger, and with *Use mouse input* off a Touch trigger ignores the mouse: [Touch](plugins/touch.md). 4. A fast second tap fires *On double-tap*, not *On tap*: [Touch](plugins/touch.md). 5. The touch starts outside the object, or in a strip that a popup's dim leaves open under *Scale outer*: [Touch](plugins/touch.md). 6. *Go to layout (by name)* names no layout: [System](plugins/system.md). |
| One click also presses a hidden button, or one behind a popup | 1. The trigger picks every instance under the pointer: [Touch](plugins/touch.md). 2. An invisible button, or one with collisions disabled, still takes the click: [Touch](plugins/touch.md). 3. A close event made the layer under the popup interactive during the same tap: [Layers](primitives/layers.md). |
| A toggle flips back, or flickers | 1. The event has no trigger, so it flips every tick: [Conditions](primitives/events/conditions.md). 2. Two events share the trigger, and the second sets the value back: [Conditions](primitives/events/conditions.md). |
| `Count` still includes a destroyed instance, or "none left" never holds | 1. A destroyed instance counts until the top-level event ends: [How events work](primitives/events/how-events-work.md). 2. `PickedCount = 0` never holds below a pick of the type: [How events work](primitives/events/how-events-work.md). 3. A destroyed child still counts as a child, and `ChildCount` counts every type: [How events work](primitives/events/how-events-work.md), [Common to all objects](plugins/_common.md). |
| A trigger never fires | 1. Its sheet is not the layout's sheet or one it includes: [Event sheet includes](primitives/events/includes.md). 2. The animation loops, so *On finished* never fires: [Sprite](plugins/sprite.md). 3. A tween started later on the same property stopped the tween: [Tween](behaviors/tween.md). 4. A timer that only its own *On timer* restarts under a condition has stopped: [Timer](behaviors/timer.md). 5. *Bounce off object* moved the bullet out before a later *On collision* event: [Bullet](behaviors/bullet.md). |
| A *Wait* never resumes, or the actions after it run too early | 1. *Use time scale* is on while the time scale is 0: [System](plugins/system.md). 2. The *Signal* ran before its *Wait for signal* started: [System](plugins/system.md). 3. A *Wait* does not stop a loop, and sibling events run at once: [System](plugins/system.md). 4. *Wait for previous actions* does not wait for a function that is not *Asynchronous*: [System](plugins/system.md). |
| A tween ends at the wrong size or position | 1. A *Set* of the property during the tween adds to the tween's change: [Tween](behaviors/tween.md). 2. Another tween started on the property stopped this one: [Tween](behaviors/tween.md). 3. A width tween ended slightly short of its target: [Tween](behaviors/tween.md). 4. *Set frame* to a frame of another image size resized the instance: [Sprite](plugins/sprite.md). |
| A value reads 0, NaN or its initial value | 1. A missing value, such as an absent key or index, reads 0: [Expressions](primitives/events/expressions.md). 2. A text set into a number variable stores NaN or its leading number: [Event variables](primitives/events/variables.md). 3. A non-static local resets every tick and at its declaration: [Event variables](primitives/events/variables.md). 4. `Tween.Value(tag)` reads 0 after the tween ends, and a Timer's expressions after *Stop*: [Tween](behaviors/tween.md), [Timer](behaviors/timer.md). 5. A created instance had no instance to copy, so its behavior properties read 0: [Templates](primitives/objects/templates.md). |
| A pause does not pause, or the game stays frozen or slow | 1. A deactivated group leaves behaviors, timers and tweens running: [How events work](primitives/events/how-events-work.md). 2. *Restart layout* and *Go to layout* keep the time scale: [System](plugins/system.md). 3. Two *Wait* hit stops overlap, or a `wallclocktime` restore leaves the game slow: [System](plugins/system.md). |
| An action after *Create object* changes the wrong instances, or misses the new one | 1. *Create object* picks the new instance in its type, not in its families: [System](plugins/system.md). 2. Until the top-level event ends, only *Pick by unique ID*, the hierarchy picks and `Count` find it outside its event: [How events work](primitives/events/how-events-work.md). |
| The editor refuses to open the project | 1. A branch holds two triggers, or a function holds one: [Conditions](primitives/events/conditions.md). 2. A System condition or action uses `Self`: [Event variables](primitives/events/variables.md). 3. A variable or parameter has the name of a system expression, such as `mid` or `round`: [Event variables](primitives/events/variables.md). 4. A Text object has *Set color*: [Text](plugins/text.md). 5. A hand-written uistate file lacks a key that the editor saves: [hand-editing.md](project-files/hand-editing.md#the-project-folder). |
| A change written on disk is gone after the editor saves | 1. The editor had the project open and saved its own copy over the file: [hand-editing.md](project-files/hand-editing.md#the-project-folder). 2. The editor drops an empty list, such as `"children": []`, at the next save of the file: [hand-editing.md](project-files/hand-editing.md#every-file). |
